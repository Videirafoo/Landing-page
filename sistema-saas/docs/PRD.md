# Requisitos (PRD)

O B.A.S.E. ajuda uma escola a administrar alunos, turmas, matrículas, docentes, presenças, notas e avisos. Visitantes veem a landing; usuários criam conta de escola ou entram com matrícula e senha; após autenticação chegam ao dashboard. Cada escola enxerga apenas os próprios registros.
