# Segurança

Senhas com scrypt e sal por usuário; mensagens genéricas de login incorreto; bloqueio temporário após repetidas tentativas; cookie de sessão HttpOnly/SameSite=Strict (Secure somente em HTTPS configurado); origem verificada em requisições mutáveis. API exige sessão e filtra registros pela escola. **Não é uma avaliação de segurança completa nem adequado para dados reais de crianças.**
