Ícones originais B.A.S.E. — SVG leve, 24 × 24, fundo transparente.
Arquivos individuais: dashboard.svg, alunos.svg, matriculas.svg, turmas.svg, professores.svg, frequencia.svg, avaliacoes.svg, conteudos.svg, comunicados.svg, relatorios.svg, indicadores.svg, configuracoes.svg, usuarios.svg.
Os ícones são máscaras CSS: azul/turquesa em repouso, laranja no hover/foco e laranja claro no item ativo.
Uso: a interface atribui data-pagina ao botão; style.css associa cada página ao arquivo SVG.
Compatível com GitHub Pages e backend Python; não requer bibliotecas nem fontes externas.
