Focos

Facilitar a vida escolar dos mais de 18.300 matriculados na rede municipal, garantindo maior segurança durante os anos de estudo.

Conectar mais de 20.000 responsáveis a mais de 70 escolas municipais, permitindo o acompanhamento das atividades acadêmicas.

Trabalhar problemas de comunicação, processamento manual de dados e acompanhamento acadêmico do aluno.

Quem Somos?

O projeto B.A.S.E. é um sistema escolar que visa melhorar o controle de informações, notas e, no geral, a interação entre pais e escola.

Como Trabalhamos?

Estamos desenvolvendo um aplicativo mobile e um site web que trabalharão em conjunto para facilitar o registro de dados e o acesso de pais e alunos às informações relevantes.
