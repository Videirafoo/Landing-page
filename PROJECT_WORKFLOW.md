# Project Workflow — Landing Page

## Perfil
Projeto acadêmico web — **processo enxuto**.

## Fluxo
Objetivo → público → conteúdo → estrutura → design → implementação → responsividade → testes → apresentação.

Cada mudança: **Entender → Planejar → Implementar → Testar → Corrigir → Commit → Atualizar README/TASKS quando necessário.**

## Documentação mínima
- README.md — como abrir/executar.
- TASKS.md — o que falta.
- DESIGN.md — apenas se houver identidade visual/regras relevantes.
- TEST_PLAN.md — checklist simples de links, formulário, mobile e desktop.

## Regras
- Código deve permanecer compatível com o nível e objetivo acadêmico do projeto.
- Priorizar HTML/CSS/JS claros em vez de complexidade desnecessária.
- Testar navegação, âncoras, links, formulário, 375px/768px/desktop.
- Não adicionar dependências sem necessidade.
- Uma mudança por vez, com commit descritivo.
