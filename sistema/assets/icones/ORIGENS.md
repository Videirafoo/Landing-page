# Ícones utilizados
Os 13 ícones de navegação são da biblioteca Lucide, hospedada em https://github.com/lucide-icons/lucide, com seus nomes adaptados para os módulos do B.A.S.E.

A implementação usa arquivos SVG estáticos e CSS mask. Não importa JavaScript do Lucide.

A licença oficial foi mantida em `LICENSE-LUCIDE.txt`; o logotipo oficial do B.A.S.E. não foi modificado.

Os quatro ícones de estados vazios do dashboard também são SVGs oficiais da Lucide, com traço de 2px e cores adaptadas à paleta B.A.S.E.:
- `chart-no-axes-combined` → `../vazio-frequencia.svg`
- `mail` → `../vazio-comunicados.svg`
- `chart-column-increasing` → `../vazio-desempenho.svg`
- `clipboard-list` → `../vazio-atividades.svg`

As formas são do projeto Lucide; o fundo discreto e o dimensionamento são definidos em `sistema/painel.css`.
